# Droid Foundry (Brainrot Galaxy Edition)

A brainrot space-opera droid-collecting simulator for Roblox. You scavenge junk planets, build a droid foundry, and open crates to collect **330 droids**, from Mouse Droids up to **12 ICONIC droids** like **R2-67, TUNG-3PO, IG-69 and BB-Ate**. You also rebirth for multipliers and jump to hyperspace across **8 planets**. Servers hold up to 10 players.

> **About names:** every droid, planet, title and currency name lives in one file, [`src/shared/Config/StarWarsNames.luau`](src/shared/Config/StarWarsNames.luau). The famous droids are parody names on purpose. Roblox can remove games that use real Disney/Lucasfilm names, so if the game ever gets flagged, rename the entries in that file and everything in the game updates.

### The planets
| # | Planet | Vibe | Set pieces |
|---|---|---|---|
| 1 | **Junkku** | Starship graveyard | Half-buried star destroyer, fallen walker, wrecked X-wing & TIE, scavenger market |
| 2 | **Sigmatooine** | Twin-sun spaceport | Two suns, domed huts, moisture vaporators, sandcrawler, YT freighter |
| 3 | **Hothdog** | Frozen rebel base | Hangar carved in an ice cliff, X-wings, AT-AT walkers, shield generator, blizzard |
| 4 | **Endor, Ohio** | Forest moon | Giant redwoods, treetop villages, shield bunker, AT-ST, fireflies, lakes |
| 5 | **Bespin Bussin** | Cloud City | Tiered floating city, domed towers, landing pad, sunset cloud sea, cloud cars |
| 6 | **Mustafanum** | Lava planet | Lava valleys & lavafalls, collector arms, dark fortress, embers |
| 7 | **Coruscan't** | Galactic capital | Five-spire temple, endless skyline, air-traffic lanes |
| 8 | **The Sigma Star** | Battle station | Hull panels, turrets, the trench, reactor beam, parked TIEs, a planet in the sky |

The landscapes are generated as **real Roblox Terrain** (dunes, snowfields, forests with water, lava valleys) or built platforms (cloud city, capital city, battle station). Each planet has its own sky, atmosphere, clouds and colour grading.

### Rarities
Common → Uncommon → Rare → Epic → Legendary (named droids, 3 per planet) → Mythic (0.1% in any crate) → **ICONIC** (0.02% in any crate, or the Robux Iconic Crate).

## Quick start

1. Install [Rojo](https://rojo.space) 7.x and the Rojo Studio plugin.
2. Build the place file:
   ```bash
   rojo build default.project.json -o DroidFoundry.rbxl
   ```
   Or run `rojo serve` and connect from Studio for live sync.
3. Open the place in Roblox Studio and press **Play**. The 8 planets (terrain included) are generated by code when the server starts, which takes a few seconds, so you don't need to build any map by hand.

### Studio / game settings
| Setting | Where | Value |
|---|---|---|
| Max players | Game Settings → Places → Server Fill | **10** |
| DataStores in Studio | Game Settings → Security → *Enable Studio Access to API Services* | On (without this, data only lasts for the session; the game still runs) |
| Avatar | Game Settings → Avatar | R15 or R6 both work |

### Monetization setup (Design Doc §7)
All 30 shop items are listed in [`src/shared/Config/Products.luau`](src/shared/Config/Products.luau).
1. On the Creator Dashboard, create each **Developer Product** and **Game Pass** at the listed Robux price.
2. Paste each numeric ID into that item's `assetId`.
3. Items left at `assetId = 0` show **COMING SOON** in the shop and can't be bought.

Receipts are recorded in the same DataStore save as the reward, so a purchase can't be granted twice.

### Audio (Design Doc §8)
[`src/shared/Config/Sounds.luau`](src/shared/Config/Sounds.luau) maps every cue: per-rarity reveals, style "shing", the rainbow glissando, hyperspace, and rebirth. The defaults are sounds bundled with the Roblox client so the game makes noise out of the box. Swap in your own `rbxassetid://` uploads for the real stingers.

## What's in the game

| Design Doc | Implementation |
|---|---|
| **§2 Currencies**: Credits 🪙 / Aura 💎 / Robux | Credits come from clicks, junk piles, and passive droid income. Aura comes from Bounty quests, rebirths, and a 5% bonus drop from Salvage crates. |
| **§3 8 worlds** | 8 planets (see the table above). Each one has its own terrain, set pieces, sky, particles, crate pool, and station multiplier (x1 → x15). |
| **§4 Rebirth** | Costs 10K × 10ⁿ. You lose Credits and upgrades. You keep droids, Aura, titles, and planets. You gain +0.5x multiplier, the next planet, a title + trail ("Rebirth V — Jedi Sigma"), a free Rare crate, and Aura. Rebirths 8+ are Prestige ("The Chosen Rizz") with hue-cycling name tags. |
| **§5.1 Droids & rarities** | 330 droids in 7 rarities (96/80/64/48/24/6/12). Every generic droid model (B1 Battle Droid, Gonk Droid, Droideka…) has a version on each planet, plus 24 named Legendaries, 6 Mythics and 12 Iconics in global pools. There are 15 hand-built 3D chassis (astromech, protocol, BB, B1, B2, droideka with shield bubble, probe, gonk, mouse, IG, KX, seeker, spider, pit, medical). |
| **§5.2 Styles** | Gold 1/40, Diamond 1/150, Shadow 1/150, Neon 1/300, Rainbow 1/1000, rolled independently of rarity. Each style has its own materials and effects (Rainbow/Neon models animate). |
| **§6.1 HUD** | Pet Sim–style layout: Credits/Aura pills and a 2×3 grid of chunky menu tiles on the left, a planet banner at the top, a big OPEN CRATE button (purple when an Aura crate is affordable) plus SALVAGE at the bottom, and REBIRTH (pulses gold with confetti when ready) plus FOUNDRY on the right. Menus blur the background. |
| **§6.2 Map Select** | Carousel of planet cards, padlocks on locked worlds, avatar bubbles for players in each world, droid pool preview, multiplier, and Travel. Travel plays a hyperspace-jump effect. |
| **§6.3 Crate opening** | The crate drops in and shakes, then cracks open in 3 taps. A rarity flash plays with a camera zoom, then a **separate** style flash with a "coating" sweep. Mythics get fireworks, and every server sees a HoloNet announcement. |
| **§6.4 Inventory** | Grid filterable by rarity, style, and map, sortable by Best / Newest / Rarity. The detail view has Station, Fuse (3 copies → ★), Style Tokens, and Recycle. There's also an Equip Best button and a collection counter. |
| **§6.5 Rebirth modal** | "You Lose" vs "You Gain" panels and a 2-second hold-to-confirm REBIRTH button with a shimmer effect. |
| **§6.6 Shop** | Tabs: Featured / Gamepasses / Crates / Currency / Styles / Bundles. The daily Deal of the Day has a countdown, and items carry BEST VALUE / LIMITED / POPULAR ribbons. |
| **§6.7 Onboarding** | An opening crawl ("A long time ago in a galaxy far, far away…", skippable), then a free first crate and a pulse-ring + arrow tutorial: Credits → Crate → Galaxy Map. |
| Tycoon | Each player gets a **foundry plot** on Junkku. The building grows with your upgrades, and your best droids stand on showcase pods. Your top 4 droids also follow you around. |

**Original twists added to the doc:**
- **Home-world bonus:** a droid stationed in the world it came from earns +25%, which gives you a reason to farm every world.
- **Bounty Board:** 3 rotating quests that pay out Aura.
- **Style Tokens:** you apply a token to a droid you choose. It isn't consumed on a random roll.

### Security model
The client never sends amounts, prices, or odds. Every action goes through a single `Request` RemoteFunction. The server validates the action, rate-limits clicks to 15/s, allows one action per player at a time, and recomputes all values from the config.

### Tuning
Pacing knobs are in `Economy.luau` (rebirth curve, upgrade costs, slots), `Crates.luau` (odds and prices), and `Worlds.luau` (multipliers). In a simulation of an active player (about 4 clicks/s, buying greedily), the first rebirth arrives after about 5.5–6 minutes. A lucky 0.1% Mythic pull gets you there much faster, which is intended as a jackpot moment.
